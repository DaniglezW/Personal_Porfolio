# Portfolio App

Bienvenido al **Portfolio** de [Tu Nombre]. Esta es una aplicación construida con **React** que muestra mis habilidades y experiencia.

![Portfolio Main Screen](src/assets/PortfolioMainScreen.png)

## Descripción

Este es un portfolio interactivo donde puedes explorar las habilidades y tecnologías que manejo. La aplicación está construida utilizando **React** y muestra una interfaz de usuario limpia y moderna. Es completamente responsiva y se adapta a diferentes tamaños de pantalla.

## Funcionalidades

- **Pantalla principal:** Muestra una visión general de mis habilidades y experiencia.
- **Sección de Habilidades:** Presenta mis principales competencias y tecnologías que manejo.
- **Formulario de contacto:** Los visitantes pueden enviarme un mensaje a través de un formulario de contacto integrado.
